# Design system

The accepted desktop and mobile concepts are committed in `docs/design/`.

- Background: matte graphite `#0b1218`
- Surfaces: slate `#101820` / `#131d25`
- Primary text: warm ivory `#f4f3ed`
- Secondary text: steel `#a3adb6`
- Success/action: acid lime `#c8e84c`
- Failure: amber `#f1bc38`; terminal errors use restrained coral
- UI type: Geist; code/metadata: Geist Mono
- Geometry: 1 px rules, 7 px panels, 5–7 px controls
- Container model: open rails, editor canvas, result list; no bento grid
- Desktop: task composer / execution workspace / policy rail
- Mobile: composer stays visible; Task, Execution, and Policy switch the lower
  workspace

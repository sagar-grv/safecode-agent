# Awwwards-inspired design direction

## Reference synthesis

The redesign borrows transferable principles from the Awwwards gallery and showcase pages rather than copying a particular site. The direction is editorial, typographic, monochrome-first, and interaction-led: one strong hero message, generous spacing, a strict grid, restrained signal color, modular sections, and progressive disclosure.

## Kavach translation

The product is organized as a single narrative path: hero statement, target boundary, run narrative, proof surface, measured signals, and safety contract. The visual system uses an ink-and-paper palette with one emerald verification color. Motion is functional: the active pipeline stage pulses during validation, controls show explicit running states, findings lift only on hover, and tabs reveal evidence without navigating away from the narrative.

## Competition guardrails

The visual language must never imply that the demo has tested real defence systems. Synthetic-demo labels, egress-denied language, and the organiser-adapter-pending notice remain visible. All findings and metrics are presented as synthetic MVP evidence until the organiser sandbox and hidden holdout are available.

## Presentation translation

The deck mirrors the product sequence. The same four-stage loop appears in matching positions so Fade or Morph transitions can connect the story across slides. Each slide adds one layer—gap, method, architecture, differentiation, and delivery—without adding unrelated decoration. Recommended delivery uses a 0.35-second Fade between slides and sequential reveals in reading order.

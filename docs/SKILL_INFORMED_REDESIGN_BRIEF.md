# Skill-informed Kavach redesign brief

## Design read

> Reading this as: a defence-security proof product for technical judges, with an authored dark-tech / industrial laboratory language, leaning toward a single dark theme, real dimensional product imagery, crisp grid typography, purposeful motion, and evidence-first interaction.

## Design dials

| Dial | Value | Rationale |
|---|---:|---|
| Design variance | 7/10 | The brief calls for a distinctive, high-impact redesign but judges must still read the proof sequence quickly. |
| Motion intensity | 6/10 | Motion should explain state and narrative progression, not decorate every element. |
| Visual density | 4/10 | The control room contains meaningful evidence; marketing and story pages should remain spacious. |

## Applied principles

The website should use one page-level visual family: dark charcoal, off-white, and a single lime verification accent. The 3D proof core is the only cinematic focal point. Headings must be short, large, and left aligned; every page should have one primary purpose.

Motion is limited to hierarchy, state feedback, and story hand-offs. User-driven interactions complete within 300 ms; entries use ease-out; interactive controls have an active press state; perpetual decorative animation remains subtle and respects `prefers-reduced-motion`.

The site must preserve semantic navigation, visible focus states, image alt text, keyboard-accessible buttons, a Back affordance, and no `transition: all`. Heavy client-side animation remains isolated from server-rendered editorial content. Static visual assets are loaded through Next Image with explicit dimensions and priority only above the fold.

The deck will mirror the same grammar. The 3D proof core appears on the cover and the persistent Discover → Reason → Patch → Prove line provides an intentional Morph/Fade hand-off between slides. Native PowerPoint animation remains a post-download action; the deck notes specify exact choreography.

## Security decision

The `ui-ux-pro-max` package was not installed because its installer reported a high generation-risk assessment. Its direct raw skill path returned 404, so no unverified package instructions were executed. The redesign instead uses the successfully installed taste, Vercel React, and animation guidance plus the publicly readable Vercel interface rules.
